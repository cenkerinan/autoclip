# V2 Roadmap

## Live Studio — AI-Native Recording & Streaming

V2 should add a StreamYard/Riverside-style live production layer after the core AI Producer/Director, editor and Ad Factory are proven.

### Core capabilities
- browser-based recording studio
- remote guests/backstage participants
- 1080p and 4K local isolated recordings
- multi-camera and extra-camera sources
- multistreaming to multiple destinations
- custom RTMP destinations
- cloud recording and storage
- pre-recorded streams
- branded layouts, logos, overlays and backgrounds
- intro/outro/video playback
- chat overlays
- custom fonts/layouts
- clean program feed and thumbnails
- downloadable transcripts
- AI backgrounds

### Differentiator: Real-Time AI Producer/Director
During recording/live production, AI should detect and timestamp:
- strong hooks
- reactions
- potential Shorts
- important quotes/reveals
- missing coverage/B-roll
- audio/video quality issues
- overly long answers
- useful follow-up questions
- suggested camera/shot changes

Live markers feed directly into the Media Intelligence Graph so post-production begins with production context already captured.

### End-to-end workflow

Plan → Record/Live → AI Direct → Media Intelligence Graph → AI Edit → Repurpose → Ad Factory → Publish → Performance Learning

### V2 principle
Architect for Live Studio in V1, but do not allow WebRTC/RTMP/live infrastructure to delay validation of the core AI Producer/Director product.
